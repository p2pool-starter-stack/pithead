# Manual release checklist (moved)

The manual QA plan for a pithead release now lives in [`manual-qa/`](manual-qa/README.md), split
into step-by-step guides a tester can follow without knowing the code:

| Part | Where |
|---|---|
| Start here: how to test, record results, glossary, run sheet, known issues | [manual-qa/README.md](manual-qa/README.md) |
| What you need, sample configs, coverage | [what-you-need.md](manual-qa/what-you-need.md), [sample-configs.md](manual-qa/sample-configs.md), [coverage.md](manual-qa/coverage.md) |
| The self-deployed (DIY) route, sections 1–12, and the sandbox VM | [manual-qa/diy/](manual-qa/diy/README.md) |
| The appliance, sections 13–15, and the M1–M13 batteries | [manual-qa/appliance/](manual-qa/appliance/README.md) |
| Scenarios, before the cut, cutting and after publishing | [manual-qa/release/](manual-qa/release/scenarios.md) |

Step IDs (1.1, 13.10, M7, S3 and so on) are unchanged.
